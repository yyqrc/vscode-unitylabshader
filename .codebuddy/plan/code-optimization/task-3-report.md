## 🔧 技术实现

### 数据结构

#### CacheDiff（缓存差异）
```typescript
interface CacheDiff {
    added: Map<string, FileSymbolCache>;      // 新增文件
    modified: Map<string, FileSymbolCache>;   // 修改文件
    deleted: Set<string>;                     // 删除文件
    stats: {                                  // 统计信息
        addedFiles: number;
        modifiedFiles: number;
        deletedFiles: number;
        addedSymbols: number;
        modifiedSymbols: number;
        deletedSymbols: number;
        totalChanges: number;
    };
}
```

#### FileChangeInfo（文件变更信息）
```typescript
interface FileChangeInfo {
    filePath: string;
    oldHash: string;
    newHash: string;
    oldSize: number;
    newSize: number;
    oldModified: number;
    newModified: number;
}
```

### 核心算法

#### 1. 三级文件变更检测
```
Level 1: 文件存在性检查
  ├─ 文件不存在 → 已删除
  └─ 文件存在 → Level 2

Level 2: 元数据检查（快速）
  ├─ 大小和时间未变 → 未变更
  └─ 大小或时间变化 → Level 3

Level 3: 内容哈希检查（精确）
  ├─ 哈希相同 → 未变更（时间戳变化）
  └─ 哈希不同 → 已变更
```

#### 2. 智能持久化策略
```
计算变更率 = 变更文件数 / 总文件数

if 变更率 > 30%:
    使用全量保存（更快）
else if 文件数 > 1000:
    使用流式写入（省内存）
else:
    使用普通增量保存（最快）
```

#### 3. 流式写入算法
```
1. 打开文件流
2. 写入缓存头部（元数据）
3. 分批写入文件缓存：
   for batch in batches(files, batchSize=50):
       写入批次数据
       释放内存
4. 写入符号索引
5. 关闭文件流
```
