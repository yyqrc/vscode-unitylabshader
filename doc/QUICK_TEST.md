# 快速测试指南

## 🚀 一键测试

### 测试1：缓存机制（最重要）
```
1. F5 启动扩展
2. 打开任意 shader 文件
3. 找到任意函数调用（如 LinearToGammaSpaceFull）
4. 按 F12 跳转
5. 查看调试控制台：Total time: ~180ms
6. 按 Alt+← 返回
7. 再次按 F12（30秒内）
8. 查看调试控制台：[Cache] ✓ Hit! ... Total time: <5ms ✅
```

**预期结果**：
- ✅ 首次：~180ms
- ✅ 缓存：<5ms（性能提升 97%）

---

### 测试2：宏函数识别
```
1. 搜索文件中的全大写函数调用
   例如：LIGHTING_RESULT_COMBINE_FUNC(...)
        UNITY_MATRIX_MVP
        TRANSFORM_TEX(...)
2. 光标放在宏函数名上
3. 按 F12 跳转
4. 查看日志：[Guess] Macro-function detected
5. 查看日志：[Performance] Macro+Function search
```

**预期结果**：
- ✅ 能跳转到宏定义或函数定义
- ✅ 日志显示 "Macro-function detected"

---

### 测试3：常用符号预加载
```
1. F5 启动扩展
2. 等待 3 秒
3. 查看调试控制台：[Preload] Loaded X common symbols
4. 找到 UnityObjectToClipPos 或 UNITY_MATRIX_MVP
5. 按 F12 跳转
6. 查看日志：[Cache] ✓ Common symbol hit!
```

**预期结果**：
- ✅ 预加载成功（启动后3秒）
- ✅ 常用符号跳转 <5ms

---

## 🐛 问题排查

### 问题1：缓存没有命中
**症状**：每次跳转都是 ~180ms，没有 <5ms 的缓存命中

**排查**：
1. 检查是否在开发模式（F5）运行
2. 查看日志是否有 `[Cache]` 相关输出
3. 确认两次跳转间隔 <30秒
4. 确认是在同一个位置跳转

**解决**：
- 确保使用 F5 启动（不是 Ctrl+F5）
- 查看调试控制台（不是终端）

---

### 问题2：宏函数跳转失败
**症状**：全大写函数跳转不到定义

**排查**：
1. 查看日志：是否显示 `[Guess] Macro-function detected`
2. 查看日志：是否显示 `[Performance] Macro+Function search`
3. 确认宏定义确实存在

**解决**：
- 检查宏定义格式：`#define MACRO_NAME ...`
- 确认文件在工作区内

---

### 问题3：预加载没有生效
**症状**：常用符号跳转仍然很慢

**排查**：
1. 查看启动日志：是否有 `[Preload] Loading common symbols...`
2. 查看启动日志：是否有 `[Preload] Loaded X common symbols`
3. 确认等待了至少 3 秒

**解决**：
- 重启扩展（F5）
- 查看是否有错误日志
